
# 1. End-To-End Excel Project on Bike Buyers Dashboard:
The entire repository will contain a project worked on in Excel using real-time datasets.

# Data Cleaning:
1. In this project, the dataset used is the bike buyers dataset for specific regions. The data had some errors; for example, marital status had M and S, which represented Married and Single, creating ambiguity with Gender M and F. To overcome this ambiguity, replaced Marital Status M with Married and S with Single, whereas in the Gender column, I replaced M with Male and F with Female.
2. The age column had whole numbers; to overcome that, create Age Brackets so that it helps to create an age range. Age < 31 as "Adolescent", Age >= 31 as "Middle Age", and Age > 54 as "Old".
